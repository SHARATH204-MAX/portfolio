04 / Projects

What I've Built

01 Full-Stack · LLM Platform · Live

SynapseSQL Enterprise — AI Database Intelligence Platform

Conversational analytics platform that turns typed or voice questions into SQL using LangChain and Groq-hosted LLMs, grounded on the live database schema to eliminate hallucinated queries. A two-pass pipeline delivers deterministic SQL generation, self-healing retries that feed DB errors back to the model, multi-model failover and streamed summaries over FastAPI Server-Sent Events. Layered security adds destructive-SQL guardrails, a read-only connection, JWT auth with admin/analyst/viewer RBAC, rate limiting and Supabase audit logs — all wrapped in a React + TypeScript UI with schema explorer, sortable data grid, charts and CSV/Excel/JSON export, containerised with Docker and deployed on Render.

Python FastAPI React TypeScript LangChain Groq PostgreSQL JWT SSE Docker Render

02 Microservices · Java · Security

FitMe — Fitness App Microservices

Microservices fitness-tracking platform built around an API Gateway with User, Activity and AI Recommendation services, service discovery through Netflix Eureka and centralized configuration via Spring Cloud Config Server. Secured with OAuth2/JWT through Keycloak as the identity provider — Spring Security validates tokens at the gateway before requests ever reach downstream services — plus automatic user synchronization from Keycloak into the internal User Service. The React + Redux (Vite) frontend handles Keycloak login and activity listing, detail and creation pages that call backend APIs through the gateway.

Java 23 Spring Boot Spring Cloud Keycloak OAuth2 React Redux Vite Docker

03 Deep Learning · MLOps · CI/CD

Kidney Disease Classification — Deep Learning Service

VGG16 transfer-learning classifier (ImageNet weights, custom head) labelling kidney CT scans as Normal or Tumor across a 7,360-image dataset, reaching 88% validation accuracy with augmentation, early stopping, learning-rate scheduling and best-model checkpointing. A reproducible ML pipeline built on DVC (ingestion → base model → training → evaluation) with typed YAML configuration and MLflow/DagsHub experiment tracking. Training issues — a diverged learning rate collapsing the model to the majority class, train/inference preprocessing mismatches and a validation-split leak — were diagnosed and fixed for reliable metrics. Ships as a Flask REST API with a drag-and-drop web UI, containerised in Docker with a GitHub Actions workflow that builds, pushes to Amazon ECR and deploys to EC2.
